Client Setup:
1. Open VSCode and change the working directory to client folder in the terminal
2. Use 'npm i' or 'npm install' to install node packages and modules
3. Enter 'npm run start' to run client

Server Setup:
1. Open VSCode and change the working directory to server folder in the terminal
2. Use 'npm i' or 'npm install' to install node packages and modules
3. Enter 'node index' to run server
